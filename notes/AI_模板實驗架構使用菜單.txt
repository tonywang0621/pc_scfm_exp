用途：
這份文件給 AI 或研究助理快速理解目前專案怎麼用。專案已改成 Single-lead ECG Baseline Wander Removal，不再是舊的 sEEG template。


一、目前專案目標

任務：
  Input：含 Baseline Wander 的 single-lead ECG。
  Output：restored ECG。
  Target：clean_reference，也就是經一致前處理後、尚未加入 Baseline Wander 的 ECG。

固定設定：
  Lead：Lead II。
  主要訓練資料：PTB-XL。
  外部測試資料：MIT-BIH、Chapman、CPSC。


二、主要程式

所有程式在：

  code/

重要檔案：

  preprocess_ecg.py
    從 ECG records 產生 train/val/test/external NPZ。
    支援 Lead II extraction、filter、resample、window、normalization、baseline wander synthesis。

  train_supervised.py
    訓練入口。讀 YAML、建立 dataset/model、訓練、保存 checkpoint、輸出 metrics/plots。

  inference.py
    對指定 NPZ 跑模型 inference，輸出 restored ECG、metrics_summary、metrics_per_window。

  experiment_suite.py
    Experiment 2、3、7 的批次實驗工具。

  result_analysis.py
    結果後處理工具。負責總表彙整、best/median/worst case 自動挑圖、paired statistics。

  utils.py / utils_ecg.py / analysis.py
    指標、圖表、complexity、ECG metric helper。


三、設定檔

目前主要 config：

  code/configs/ecg_baseline_wander_mecg_e.yaml
  code/configs/ecg_baseline_wander_mambattention.yaml

可用模型名稱：

  mecg_e
  mambattention_ecg

train_supervised.py 預設 config：

  configs/ecg_baseline_wander_mecg_e.yaml


四、資料切分

PTB-XL 使用 DISR-ECG 論文相同官方 fold：

  train.npz：PTB-XL folds 1-8，約 80%。
  val.npz：PTB-XL fold 9，約 10%。
  test.npz：PTB-XL fold 10，約 10%。

外部測試：

  mit_bih.npz：100% test only。
  chapman.npz：100% test only。
  cpsc.npz：100% test only。

外部資料不可用於 training、validation、early stopping、checkpoint selection。

六、基本執行流程

進入 code：

  cd /mnt/c/Users/中研院/rl_exp/code

產生 PTB-XL NPZ：

  python preprocess_ecg.py \
    --config configs/ecg_baseline_wander_mecg_e.yaml \
    --input-dir /path/to/ptbxl_records \
    --metadata-csv /path/to/ptbxl_database.csv \
    --noise-dir /path/to/nstdb_records \
    --dataset-name ptbxl

訓練 MECG-E：

  python train_supervised.py --config configs/ecg_baseline_wander_mecg_e.yaml

訓練 MambAttention：

  python train_supervised.py --config configs/ecg_baseline_wander_mambattention.yaml

獨立 inference：

  python inference.py \
    --config configs/ecg_baseline_wander_mecg_e.yaml \
    --checkpoint /path/to/best_pcc_model.pt \
    --input /mnt/c/Users/中研院/data/ecg_baseline_wander/processed/test.npz \
    --output-dir /mnt/c/Users/中研院/rl_exp/runs/ecg_baseline_wander/inference/mecg_e_test

十、評估指標

MECG-E 對齊指標：

  SSD
  MAD
  PRD
  CosSim

Baseline Wander 指標：

  Output_SNR_dB
  SNR_Improvement_dB
  LF_Reduction_dB

Morphology 指標：

  R_Peak_Timing_Error_ms
  RR_Interval_MAE_ms
  QRS_Amplitude_Error

Complexity：

  Parameters
  Trainable_Parameters
  FLOPs
  Inference_Time_ms
  Peak_Memory_MB

注意：
  MAD 指 Maximum Absolute Distance，不是 mean absolute deviation。
  FLOPs 需要 thop；沒裝 thop 時為 NaN。
  no-reference input 只能計算 LF_Reduction_dB 等不需要 clean_reference 的指標。


十一、請 AI 幫忙時建議提問

4. 彙整結果：
   請幫我用 result_analysis.py aggregate 和 paired-stats 彙整成論文用表格。

5. 挑圖：
   請幫我用 result_analysis.py select-cases 自動挑 PRD 最佳、中位、最差案例圖。
