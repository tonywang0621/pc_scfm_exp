五、資料格式

每個 NPZ 必須包含：

  noisy_ecg
  clean_reference

或替代 key：

  input
  target

建議標準 key：

  noisy_ecg        加入 baseline wander 的 ECG，模型 input。
  clean_reference 尚未加入 baseline wander 的 clean reference，模型 target。

shape：

  [N, T]

或：

  [N, 1, T]

目前 YAML 預設：

  window_size: 512
  resample_hz: 360
  normalization: endpoint_center

建議 shape：

  [N, 1, 512]

dtype：

  float32


六、資料切分原則

PTB-XL 採用 DISR-ECG 論文相同官方 folds：

  train.npz：PTB-XL folds 1-8，約 80%。
  val.npz：PTB-XL fold 9，約 10%。
  test.npz：PTB-XL fold 10，約 10%。

這是 patient-wise split，用來避免 data leakage。

外部測試資料：

  mit_bih.npz：100% test only。
  chapman.npz：100% test only。
  cpsc.npz：100% test only。

外部資料不可用於：

  training
  validation
  early stopping
  checkpoint selection
  hyperparameter tuning


七、如何產生 NPZ

進入 code：

  cd /mnt/c/Users/中研院/rl_exp/code

產生 PTB-XL train/val/test：

  python preprocess_ecg.py \
    --config configs/ecg_baseline_wander_mecg_e.yaml \
    --input-dir /path/to/ptbxl_records \
    --metadata-csv /path/to/ptbxl_database.csv \
    --noise-dir /path/to/nstdb_records \
    --dataset-name ptbxl

PTB-XL metadata CSV 必須有其中一個欄位：

  strat_fold
  fold
  ptbxl_fold

產生 Chapman external test：

  python preprocess_ecg.py \
    --config configs/ecg_baseline_wander_mecg_e.yaml \
    --input-dir /path/to/chapman_records \
    --noise-dir /path/to/nstdb_records \
    --dataset-name chapman

產生 MIT-BIH external test：

  python preprocess_ecg.py \
    --config configs/ecg_baseline_wander_mecg_e.yaml \
    --input-dir /path/to/mit_bih_records \
    --noise-dir /path/to/nstdb_records \
    --dataset-name mit_bih

產生 CPSC external test：

  python preprocess_ecg.py \
    --config configs/ecg_baseline_wander_mecg_e.yaml \
    --input-dir /path/to/cpsc_records \
    --noise-dir /path/to/nstdb_records \
    --dataset-name cpsc

preprocess_ecg.py 支援：

  NPZ
  NPY
  CSV / TXT numeric arrays
  WFDB records，如果有安裝 wfdb

處理流程：

  讀 ECG -> 選 Lead II -> filter -> resample -> window -> normalize -> 合成 baseline wander -> 輸出 NPZ


八、Baseline Wander 合成

YAML 設定：

  baseline_wander:
    train_source: nstdb
    alpha_mode: peak_to_peak_ratio
    alpha_values: [0.05, 0.1, 0.2, 0.3, 0.5]
    controlled_frequencies_hz: [0.05, 0.1, 0.2, 0.3, 0.5, 0.8, 1.0]
    test_types:
      - nstdb
      - sinusoidal
      - multi_sine
      - random_low_frequency_drift

preprocess_ecg.py 已實作 baseline synthesis。

可指定 baseline 類型：

  --baseline-kind nstdb
  --baseline-kind sinusoidal
  --baseline-kind multi_sine
  --baseline-kind random_low_frequency_drift

可指定強度：

  --alpha-values 0.05,0.1,0.2,0.3,0.5

可指定頻率：

  --frequencies-hz 0.05,0.1,0.2,0.3,0.5,0.8,1.0

十二、評價指標

MECG-E 對齊指標：

  SSD
    Sum of Squared Distances，越低越好。

  MAD
    Maximum Absolute Distance，越低越好。
    注意：不是 mean absolute deviation。

  PRD
    Percentage Root-Mean-Square Difference，越低越好。

  CosSim
    Cosine similarity，越高越好。

Baseline Wander 指標：

  Output_SNR_dB
    restored ECG 相對 clean reference 的 SNR，越高越好。

  SNR_Improvement_dB
    output SNR - input SNR，越高越好。

  LF_Reduction_dB
    input ECG 與 restored ECG 的低頻能量下降，越高越好。

Morphology 指標：

  R_Peak_Timing_Error_ms
    越低越好。

  RR_Interval_MAE_ms
    越低越好。

  QRS_Amplitude_Error
    越低越好。

Complexity：

  Parameters
  Trainable_Parameters
  FLOPs
  Inference_Time_ms
  Peak_Memory_MB

注意：

  FLOPs 需要安裝 thop；沒裝時會是 NaN。
  Peak_Memory_MB 是 CUDA peak memory；CPU memory 沒有正式量測。
  沒有 clean_reference 的資料只能算 no-reference 指標，例如 LF_Reduction_dB。

二十、如何判斷結果

主要看：

  PRD 越低越好。
  SSD / MAD 越低越好。
  CosSim 越高越好。
  SNR_Improvement_dB 越高越好。
  LF_Reduction_dB 越高越好。
  R_Peak_Timing_Error_ms 越低越好。
  RR_Interval_MAE_ms 越低越好。
  QRS_Amplitude_Error 越低越好。

再看圖：

  prediction_sample_*.png
  spectrum_sample_*.png
  best/median/worst case plots

重點：

  baseline drift 是否下降。
  QRS 是否保留。
  T wave 是否被削掉。
  ST segment 是否被扭曲。
  residual error 是否主要集中在低頻漂移，而不是 ECG 主形態。

二十二、常見問題

1. 找不到資料

確認：

  data_dir 是否正確。
  processed/train.npz 是否存在。
  processed/val.npz 是否存在。
  processed/test.npz 是否存在。

2. PTB-XL fold 錯誤

如果 NPZ 內有 fold / strat_fold / ptbxl_fold metadata，dataset loader 會檢查：

  train 只能是 folds 1-8。
  val 只能是 fold 9。
  test 只能是 fold 10。

3. shape 錯誤

只接受：

  [N, T]
  [N, 1, T]

不接受：

  [N, 12, T]

如果是 12-lead ECG，先用 preprocess_ecg.py 抽 Lead II。

4. mamba_ssm import error

代表環境沒有裝 Mamba SSM。

5. FLOPs 是 NaN

代表沒有安裝 thop。
訓練仍可進行，只是 complexity_summary.yaml 的 FLOPs 為 NaN。
