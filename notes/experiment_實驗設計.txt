Single-lead ECG Baseline Wander Removal 實驗環境設計交接文件
日期：2026-07-20
來源：experiment_design_review_meeting_1.pptx


一、研究目標

本研究目標是建立一個具備高效能與泛化能力的 Single-lead ECG Baseline Wander Removal 模型。

任務定義：
- Input：含 Baseline Wander 的 single-lead ECG。
- Output：去除 Baseline Wander 後的 restored ECG。
- Clean reference / Ground truth：經一致前處理後、尚未加入 Baseline Wander 的 ECG。

重要說明：
- 本研究中的 ground truth 應稱為 clean reference 較精確。
- 若 clean reference 是由 band-pass filter 或其他前處理得到，它不是完全原始且絕對乾淨的生理訊號，而是本實驗定義下的參考目標。
- 文件與簡報中建議統一使用「clean reference」或「ground truth clean reference」，避免被質疑 ground truth 定義不嚴謹。

核心要求：
- 去除 Baseline Wander。
- 保留 ECG 臨床形態，例如 P wave、QRS complex、T wave、ST segment、R-peak 與 RR interval。
- 在跨資料集、跨醫院、跨設備與跨族群條件下仍能保持穩定表現。
- 模型計算成本需具備實務應用可行性。


二、使用 Multi-lead Dataset 但固定 Lead II 的理由

雖然研究目標是 single-lead ECG，但可以從 multi-lead ECG dataset 中固定抽取 Lead II，建立一致的 single-lead 實驗環境。

選擇 Lead II 的理由：
- Lead II 是臨床上常用導程。
- P wave、QRS complex、T wave 通常較清楚。
- PTB-XL、MIT-BIH、Chapman、CPSC 等資料集皆可取得或對應 Lead II。
- 所有資料集固定使用同一導程，可降低導程差異造成的比較偏差。

建議在方法章清楚寫成：
All datasets are converted into a consistent single-lead setting by extracting Lead II.


三、資料集角色

1. PTB-XL
- 角色：主要訓練資料集、in-domain test 資料集。
- 特性：12-lead ECG、約 21,000 筆 ECG、約 18,000 位病人、500 Hz。
- 用途：學習 ECG morphology 與 Baseline Wander Removal 任務。

2. MIT-BIH Arrhythmia
- 角色：Cross Dataset 測試資料集。
- 特性：經典 arrhythmia dataset、48 位病人、2-lead ECG。
- 用途：驗證模型在不同資料分布下的泛化能力。

3. Chapman
- 角色：Cross Hospital 測試資料集。
- 特性：約 45,000 筆 ECG、12-lead ECG、來自不同醫院與不同疾病族群。
- 用途：驗證模型在跨醫院資料上的泛化能力。
- 注意：若未使用 hospital metadata 進行 subgroup 分析，較精確的解讀應是 external dataset generalization，而不是嚴格的 hospital-level causal conclusion。

4. CPSC
- 角色：Cross Device / Cross Population 測試資料集。
- 特性：大型 ECG dataset，包含不同設備、不同醫院與不同族群。
- 用途：驗證模型在跨設備與跨族群條件下的泛化能力。
- 注意：若 device 或 population metadata 不完整，應將結果解讀為 external generalization，並避免過度宣稱模型已完整驗證所有設備或族群。

整體設計：
- PTB-XL 用於訓練與 in-domain 評估。
- MIT-BIH、Chapman、CPSC 僅作 external test，不參與訓練、不參與 validation、不參與模型選擇。


四、資料前處理流程

所有資料集應採用一致前處理流程，避免資料處理差異影響模型比較。

建議流程：
1. 讀取原始 ECG。
2. 選取 Lead II。
3. 統一取樣率。
4. 建立 clean reference。
5. Normalization。
6. 固定長度切片。
7. 加入 Baseline Wander。
8. 產生 model input。
9. 使用未加入 Baseline Wander 的 clean reference 作為訓練與評估目標。

投影片原先流程：
Raw ECG -> Lead II -> Band-pass Filter (0.5-40 Hz) -> Normalization -> Fixed-length slicing -> Add Baseline Wander (NSTDB) -> Model Input

建議修正：
- 此流程可保留作為一個前處理候選設定，但不建議直接把 0.5-40 Hz band-pass 視為唯一標準設定。
- 對 Baseline Wander Removal 任務而言，0.5 Hz high-pass 可能已先移除一部分 baseline drift，會讓模型任務變得不夠乾淨，也可能影響 ST segment 或 T-wave 低頻形態。
- 較穩健的主設定建議使用較保守的 filtering，例如 low-pass 40 Hz，或 0.05-40 Hz / 0.1-40 Hz band-pass。
- 若仍使用 0.5-40 Hz，應將它明確標示為 clean reference construction choice 或 sensitivity analysis，而不是無條件的真實 ground truth。

所有前處理設定需補充以下細節：
- Filter type，例如 Butterworth。
- Filter order。
- 是否使用 zero-phase filtering，例如 filtfilt。
- Resampling rate。
- Window length。
- Overlap ratio。
- Normalization 方法，例如 z-score 或 min-max。
- Baseline Wander scaling 方式。

關鍵注意：
- Clean reference 的建立方式必須和 evaluation metrics 的定義一致。
- 若前處理已移除 0-0.5 Hz 低頻成分，後續再用 0-0.5 Hz power reduction 評估 baseline removal 時要特別說明計算位置，避免指標被前處理污染。
- Reference-based metrics 僅適用於人工合成 Baseline Wander 且有 clean reference 的實驗；real-world no-reference test 不能直接使用 PRD、RMSE、SNR、cosine similarity 等需要 clean reference 的指標。


五、資料切分原則

PTB-XL 必須採用與 DISR-ECG 論文相同的官方 fold 切分，並維持 patient-wise split，避免 data leakage。

固定切分比例與 fold：
- Training set：約 80%，使用 PTB-XL official folds 1-8。
- Validation set：約 10%，使用 PTB-XL official fold 9。
- In-domain test set：約 10%，使用 PTB-XL official fold 10。

對應論文設定：
- DISR-ECG 在 training 與 in-domain evaluation 使用 PTB-XL。
- 論文明確採用官方資料切分：training = folds 1-8，validation = fold 9，testing = fold 10。
- 本實驗若使用 PTB-XL，資料切分比例固定為 80 / 10 / 10，不再另行隨機切分。

外部測試：
- MIT-BIH：test only。
- Chapman：test only。
- CPSC：test only。

規則：
- 同一病人的 ECG 不可同時出現在 train、validation、test。
- External test datasets 不可用於 hyperparameter tuning。
- 所有模型必須使用相同切分、相同前處理、相同 Lead II 輸入、相同 Baseline Wander 合成規則。
- Baseline model 尚未決定前，應先固定實驗環境，避免之後因模型選擇改變資料設定。


六、Baseline Wander 合成設計

Baseline Wander 合成規則是本實驗環境的關鍵，必須可重現。

基本公式：
noisy_ecg = clean_reference + alpha * baseline_wander

其中：
- clean_reference：經一致前處理後、尚未加入 Baseline Wander 的 ECG。
- baseline_wander：由 NSTDB 或人工方式產生的低頻漂移。
- alpha：控制 Baseline Wander 強度的 scaling factor。

主要訓練污染：
- 使用 NSTDB Baseline Wander。
- 從 NSTDB 隨機取樣 baseline segment。
- 將 baseline segment 裁切或重取樣到與 ECG window 相同長度。
- alpha 對齊 DeepFilter（Romero et al. 2021）官方 Data_Preparation 的雜訊縮放：
  noise 先以自身 peak-to-peak 範圍正規化，alpha（對應論文的 delta）從
  randint(20, 200) / 100（0.2–2.0 的整數百分比均勻抽樣）取樣，再乘上 clean ECG 的
  peak-to-peak 範圍（對應 `dataset.baseline_wander.noise_sampling: deepfilter`、
  `alpha_sampling: integer_percent_uniform`、`alpha_values: [0.2, 2.0]`）。

控制變因測試：
- Sinusoidal baseline。
- Multi-sine baseline。
- Random low-frequency drift。
- NSTDB real baseline。

建議強度設定（Experiment 2 robustness sweep 專用，固定 alpha 逐一測試）：
- 對齊 DeepFilter／MECG-E 論文回報的 noise-amplitude 分段：0.2–0.6、0.6–1.0、
  1.0–1.5、1.5–2.0（對應 `robustness_alpha_values: [0.2, 0.6, 1.0, 1.5, 2.0]`）。

建議頻率設定：
- 0.05、0.1、0.2、0.3、0.5、0.8、1.0 Hz。

目的：
- 測試模型是否能處理不同 Baseline Wander 強度。
- 測試模型是否能處理不同 Baseline Wander 頻率。
- 測試模型是否只 overfit NSTDB 的特定低頻型態。


七、實驗設計

Experiment 1：In-domain Performance
- Train：PTB-XL。
- Test：PTB-XL held-out test set。
- 目的：評估模型在同資料集上的 Baseline Wander Removal 效能。

Experiment 2：Robustness - Baseline Strength
- Train：PTB-XL。
- Test：PTB-XL with different Baseline Wander strengths。
- 強度：5%、10%、20%、30%、50%。
- 目的：評估模型在不同污染強度下的魯棒性。

Experiment 3：Robustness - Baseline Frequency
- Train：PTB-XL。
- Test：PTB-XL with different Baseline Wander frequencies。
- 頻率：0.05、0.1、0.2、0.3、0.5、0.8、1.0 Hz。
- 目的：評估模型對不同低頻漂移的適應能力。

Experiment 4：Cross Dataset
- Train：PTB-XL。
- Test：MIT-BIH。
- 目的：驗證跨資料集泛化能力。

Experiment 5：Cross Hospital / External Hospital Dataset
- Train：PTB-XL。
- Test：Chapman。
- 目的：驗證跨醫院泛化能力。
- 解讀：若可取得 hospital metadata，建議進一步做 subgroup analysis；若不可取得，則將此實驗解讀為 external dataset generalization。

Experiment 6：Cross Device / Cross Population / External Population Dataset
- Train：PTB-XL。
- Test：CPSC。
- 目的：驗證跨設備與跨族群泛化能力。
- 解讀：若可取得 device、hospital 或 population metadata，建議進一步做 subgroup analysis；若不可取得，則將此實驗解讀為 external dataset generalization。

Experiment 7：Ablation Study
- Train：PTB-XL。
- Test：PTB-XL held-out test set，建議額外加入至少一個 external test set。
- 目的：驗證模型各模組的貢獻。
- 可測項目：attention block、frequency block、residual block、loss function、conditioning strategy。

Experiment 8：Complexity Analysis
- 比較項目：parameters、FLOPs、inference time、memory usage。
- 目的：評估模型是否具有實務部署可行性。

Experiment 9：Real-world No-reference Test
- Test：原本就含 Baseline Wander 的真實 ECG。
- Ground truth：無。
- 目的：補足 synthetic test 無法完全代表真實污染的限制。
- 評估方式：去除前後波形比較、PSD 或 spectrogram、低頻能量下降、R-peak detection 穩定度、必要時加入專家定性評分。


八、評估指標設計

建議將 metrics 分成 Primary、Secondary、Optional 三層。正式簡報與主要表格以 Primary 為主，Secondary 作為補充，Optional 視實作成熟度決定是否加入。

適用範圍：
- SSD、MAD、PRD、RMSE、SNR improvement、cosine similarity 等 reference-based metrics 僅適用於有 clean reference 的 synthetic evaluation。
- Real-world no-reference test 沒有 clean reference，應使用 no-reference analysis，例如低頻能量變化、PSD/spectrogram、R-peak detection 穩定度與視覺檢查。
- 所有 metrics 的計算都應在相同 normalization 與相同 window 對齊條件下進行。

MECG-E 論文對齊指標：
- 為了和 MECG-E: Mamba-based ECG Enhancer for Baseline Wander Removal 的結果表格對齊，本研究需至少回報 SSD、MAD、PRD、CosSim。
- SSD、MAD、PRD：數值越低越好。
- CosSim：數值越高越好。
- 這四個指標皆需使用 restored ECG 與 clean reference 計算，因此僅適用於 synthetic Baseline Wander evaluation 或其他有 clean reference 的資料。

Primary metrics：

1. PRD (%)
- 衡量 restored ECG 與 clean reference 的整體差異。
- 數值越低越好。
- 適合作為主要去除效果指標。
- 僅適用於有 clean reference 的實驗。

2. SNR improvement
- 衡量去除 Baseline Wander 後訊號品質是否提升。
- 建議回報 output SNR 與 SNR improvement。
- 數值越高越好。
- 在 synthetic evaluation 中，noise 可定義為 restored ECG 與 clean reference 的差值。
- 建議明確寫出公式，例如 SNR = 10 log10(sum(clean_reference^2) / sum((clean_reference - restored_ecg)^2))。
- Real-world no-reference test 不應回報同一定義的 SNR。

3. Low-frequency power reduction
- 比較去除前後 0-0.5 Hz 或 0-0.7 Hz 的低頻能量。
- 直接對應 Baseline Wander 是否被抑制。
- 數值越高通常代表低頻漂移去除越明顯，但需搭配 morphology 指標避免過度濾波。
- 此指標應比較 model input 與 restored output 的低頻能量，而不是比較已被 high-pass filter 過的 clean reference。
- 若前處理使用 0.5 Hz high-pass，需避免再用 0-0.5 Hz 作為主要低頻評估範圍，或必須明確說明此指標是在加入 Baseline Wander 後才計算。

4. R-peak timing error / RR interval MAE
- 衡量去除 Baseline Wander 後是否保留心跳時序。
- 數值越低越好。
- 這是 morphology preservation 中最穩定、較容易自動化的指標。
- 需固定 R-peak detector，並對所有模型使用同一個偵測器與同一套參數。

Secondary metrics：

1. SSD (Sum of Squared Distances)
- MECG-E 論文使用的主要距離指標之一。
- 衡量 restored ECG 與 clean reference 的逐點平方誤差總和。
- 數值越低越好。
- 公式可寫為 SSD = sum((restored_ecg - clean_reference)^2)。
- 注意：SSD 會隨 window length、normalization scale、lead 數量改變，因此所有模型必須在相同長度與相同尺度下比較。

2. MAD (Maximum Absolute Distance)
- MECG-E 論文使用的主要距離指標之一。
- 衡量 restored ECG 與 clean reference 之間最大的逐點絕對誤差。
- 數值越低越好。
- 公式可寫為 MAD = max(abs(restored_ecg - clean_reference))。
- 注意：此處 MAD 指 Maximum Absolute Distance，不是 mean absolute deviation。

3. RMSE
- 衡量 restored ECG 與 clean reference 的逐點誤差。
- 容易受振幅尺度影響，因此不建議單獨作為主指標。

4. Cosine similarity / CosSim
- 衡量 restored ECG 與 clean reference 的整體波形方向與形狀相似度。
- 數值越高越好。
- 適合作為 global waveform similarity 的輔助指標。
- 限制：對振幅縮放不敏感，對局部 ST/T/QRS 變形也可能不敏感，因此不能取代 PRD、SNR 或 morphology 指標。
- 為了和 MECG-E 論文命名一致，主要表格中可寫作 CosSim。
- 建議使用 window-wise centered cosine similarity，也就是每個 window 先做 mean removal 或使用與模型輸入一致的 normalization 後再計算。
- 不建議在含明顯 DC offset 或未對齊的訊號上直接計算 cosine similarity。

5. QRS amplitude error
- 衡量 QRS 振幅是否被模型削弱或扭曲。
- 適合作為補充 morphology 指標。
- 需固定 QRS 或 R-peak detection 方法，並在相同 beat alignment 條件下計算。

6. Visual comparison and spectrum analysis
- 比較 input、restored output、clean reference、residual error、PSD 或 spectrogram。
- 對 ECG denoising 任務很重要，因為數值指標不一定能反映臨床形態破壞。

Optional metrics：

1. ST segment deviation
- 臨床意義高，但需要可靠 ST segment 定位。
- 若沒有穩定 ECG delineation 工具，不建議列為主指標。

2. T-wave morphology error
- 可評估 T wave 是否被扭曲。
- 自動量測難度較高，建議作為進階分析。

3. Downstream classification accuracy
- 可驗證 denoising 是否幫助診斷模型。
- 但會引入另一個分類模型與額外變因，不建議放在第一版核心實驗。

建議主要結果表格欄位：
- SSD
- MAD
- PRD
- CosSim
- SNR improvement
- Low-frequency power reduction
- R-peak timing error 或 RR interval MAE
- Parameters
- FLOPs
- Inference time


九、比較方法與統計分析

Baseline model 目前尚未決定，因此本文件不固定比較模型清單。

但一旦比較模型確定，公平性應分成「固定任務條件」與「模型專屬訓練條件」兩層處理。

固定任務條件必須一致：
- 相同 train / validation / test split。
- 相同前處理流程。
- 相同 Lead II 輸入。
- 相同 Baseline Wander 合成方式。
- 相同 evaluation metrics。
- 相同 external test datasets，且 external test 不參與任何模型選擇。

模型專屬訓練條件不必強制一致：
- Training recipe 不應無條件套用同一組 optimizer、learning rate、scheduler、batch size 或 epoch 數。
- 較合理的公平性是讓每個 baseline 盡量使用其原論文或官方實作所報告的最佳訓練 recipe，先讓各模型站在論文描述的強狀態，再放到本研究定義的同一個 Baseline Wander Removal 任務上比較 performance。
- 若原論文沒有完整公開 recipe，應採用官方 repo、作者釋出的 config、或後續 reproducing paper 中最接近的設定；若仍不可得，才使用統一 fallback recipe，並在表格註記。
- 對本文提出的方法，training recipe 可使用本研究調出的最佳設定，但 tuning budget、validation set 與模型選擇規則需與 baseline 一樣透明。
- 所有模型允許使用不同 loss function，因為 loss 本身通常是方法的一部分；但最終比較只能用同一套 evaluation metrics，不能直接比較 training loss。
- Hyperparameter tuning 原則要一致：只能看 PTB-XL validation fold 9，不能看 PTB-XL test fold 10 或 external test results 來調參。
- 每個模型需保留一份 recipe manifest，記錄 optimizer、learning rate、scheduler、batch size、epoch/iteration budget、early stopping、loss、model selection metric、資料視窗長度與所有和原論文不同之處。

Early stopping 與模型選擇原則：
- Model selection 僅使用 PTB-XL validation fold 9。
- External test datasets，包括 MIT-BIH、Chapman、CPSC，不得用於 early stopping、checkpoint selection 或 hyperparameter tuning。
- 為了讓各模型都有足夠機會收斂，主要比較採 convergence-controlled training：max epoch 統一設為 50000，early stopping patience 統一設為 20 epochs，early_stopping_min_delta 統一設為 1.0e-4。
- Optimizer、learning rate、scheduler、batch size、weight decay 與模型 loss 仍優先依各模型原論文或官方實作設定；只有在原設定於本 benchmark 明顯不足或論文未指定時，才作必要調整並註明。
- 為避免某模型因無限制訓練取得不公平優勢，需事先固定上述 stopping policy，並在報告中列出 wall-clock time、epoch/iteration 數與 best checkpoint 出現位置。
- 每個模型至少應在固定 validation interval 下同步記錄同一套 validation metrics，方便檢查是否 overfit 或過早停止。
- 主要模型選擇指標使用 validation PRD mean，因為 PRD 是 MECG-E 主表使用的核心 reference-based distortion metric，且 lower is better。
- Validation PRD 需改善至少 1.0e-4 才視為有效改善並重置 patience，避免浮點誤差或極小波動延後 early stopping。
- Validation 階段同步記錄 validation loss、PCC、PRD、SNR improvement、low-frequency power reduction、R-peak timing error 與 RR interval MAE，作為 sanity check 與訓練曲線分析；這些指標不直接作為跨模型 training loss 比較。
- 主要回報 checkpoint 採用 best validation PRD checkpoint。
- 同時保存 best validation loss checkpoint 與 best validation PCC checkpoint 作為輔助分析，但正式主結果以 best validation PRD checkpoint 為準。
- 若 validation PRD 無改善但 validation loss 或 PCC 改善，可保存對應輔助 checkpoint，但不重置 patience，也不改變主要模型選擇標準。
- Validation loss 因各模型 loss 組成不同，不可作為跨模型效能比較指標；尤其 PC-SCFM 含有 flow、behavior cloning、value 與 risk 等 auxiliary losses。
- 訓練結束後可輸出 best validation loss / PCC checkpoint 的測試結果作為診斷，但正式表格、統計分析與 robustness summary 必須預設使用 best validation PRD checkpoint。
- 正式 ablation summary 預設只彙整 best validation PRD checkpoint；best validation loss / PCC checkpoint 僅在輔助分析時另行納入。
- PTB-XL train / validation / test NPZ 必須包含 fold metadata，loader 需強制檢查 folds 1-8 / 9 / 10 是否符合設定。

Baseline recipe 對齊現況（2026-08 已逐一對照論文 / 官方原始碼修正，細節見各 config
註解與各 src/models/*.py docstring；驗證來源見下）：
- 共用前處理（8 個 baseline + 所有 mambattention/pc_scfm 消融 + 提出的方法都一致，讀
  同一份 processed/*.npz）：360 Hz resample、512 樣本不重疊切窗、endpoint-center、
  Butterworth order-4 zero-phase 0.05-40 Hz clean reference、NSTDB baseline wander 以
  integer-percent peak-to-peak ratio [0.2, 2.0] 縮放（DeepFilter Data_Preparation:
  randint(20,200)/100）。由 preprocess_common.yaml 產生。
- 訓練 recipe 採「paper optimizer + unified convergence control」：optimizer、learning
  rate、scheduler、batch size、weight decay、loss 優先對齊原論文或官方碼；主要比較的
  max epoch 統一為 50000，early stopping patience 統一為 20，min_delta 統一為 1.0e-4，
  model selection 統一使用 validation PRD mean。DeScoD 仍保留 Adam 1e-3 /
  StepLR(150,0.1) / batch 96；EDDM 保留 RAdam 1e-5 / batch 64 + ReduceLROnPlateau；
  MECG-E 保留 AdamW betas[0.8,0.99] wd 1e-2 / lr 1e-4 / ExponentialLR 0.99 / batch 96；
  proposed MambAttention CFM U-Net BD 保留其收斂用 ReduceLROnPlateau recipe。
- FCN-DAE：架構/activation/BN/init/loss(MSE)/optimizer 對齊 Chiang 2019 + DeepFilter
  復現；修了 decoder 長度重建 bug。視窗/正規化用共用 benchmark 的 512 + endpoint-center
  （非 Chiang 原本 1024 + min-max [0,1]）—— 這正是 DeepFilter/MECG-E/DeScoD/EDDM 報
  FCN-DAE 時用的設定。
- DRNN：LSTM(64) + 2×Dense(64,ReLU) + Linear、MSE 對齊 Antczak「best network overall」。
  論文的 synthetic 動力模型（McSharry ECGSYN）預訓練 + fine-tune（主貢獻）未重現 ——
  明確標為 DRNN architecture-only baseline。
- DeepFilter：對齊官方 fperdigon/DeepFilter deep_filter_model_I_LANL_dilated 逐行 ——
  6 個 MKLANL 模組、dilated 模組只有 kernels 5/9/15（無 kernel-3）/ 6 branch、
  module→Dropout(0.4)→BN、kernel-9 linear 輸出、combined_ssd_mad_loss = max(err²)·50
  + sum(err²)。Keras 層預設（glorot init、BN momentum 0.99 / eps 1e-3）已 pin。
- DeScoD-ECG：對齊官方 HuayuLiArizona/Score-based-ECG-Denoising + 論文 Fig 2 ——
  HNF blocks、5 個 HNF（dilations 1/2/4/2/1）、5 個 Bridge（FiLM）、feats=64（repo
  config 的 80 不是論文模型，論文 Table VII 參數量 1.22M 對應 64）、Kaiming init、
  quad beta schedule T=50、L1-sum loss（官方碼，非論文 Eq.12 的 L2）。1-shot = 單次
  reverse、不平均。（官方碼 zip 把最後一個 HNF 截掉，我們照 Fig 2 保留全部 5 個。）
- EDDM：對齊論文方程式 —— dual-path 擴散 Eq.5、reverse Eq.7、posterior Eq.6、L2 雙路
  loss Eq.8、T=50、雙 U-Net + self-attention + 第一個 skip 上的 DAPP。修了 beta_bar_T
  （原本 ≈0.03 → 1，論文 §III-B「x_T = x_tilde + eps」）。論文無公開 repo，alpha_t/
  beta_t 的線性下降閉式、DAPP pool scales、U-Net 通道寬度是依限制條件 best-effort 重建。
- MECG-E：config 每個值 = 官方 config/MECGE_phase.yaml；架構/loss(time+com+con, 0.5
  權重)/Hann STFT/AdamW recipe 對齊 khhungg/MECG-E pipeline.py。官方 grad clipping 是
  註解掉的 → grad_clip_norm: null。
- FIR/IIR：對齊 DeepFilter §5.2 / 官方 digitalFilters/dfilters.py ——
  IIR order=4、Butterworth、cutoff=0.67Hz、zero-phase filtfilt；
  FIR kaiserord ripple_db = 61/2 = 30.5 dB → beta 2.187、numtaps 8079（論文「order of
  8079 and a beta of 2.18」）—— 用 fixed_order 直接 pin（scipy 現在的 kaiserord 會把
  transition width 內部再除以 2，回 ~16150 taps）。套在 512 視窗上用 DeepFilter 的鏡像
  padding + filtfilt + 取中段。之前「改用 order=56」的折衷（另一篇 docs/fir_iir_filter.pdf
  的最佳值）已放棄，改回 DeepFilter 8079。
- 本文模型：可採用本研究 validated recipe（proposed 的 cfm_unet_bd 用 ReduceLROnPlateau
  + 非常有耐心的 early stopping 確保收斂），但必須和 baselines 使用同一 PTB-XL validation
  fold 9 做 tuning 與 checkpoint selection。

統計分析建議：
- 對每個 ECG window 計算指標。
- 每個 dataset 回報 mean ± standard deviation。
- 模型間比較使用 paired statistical test。
- overlap_ratio 已改為 0（不重疊切窗），window-wise samples 之間不再有重疊樣本點，較接近獨立假設；但同一筆紀錄／同一位病人切出的多個 window 彼此仍非完全獨立（同源訊號、時間相鄰）。
- Record-level／patient-level aggregation 已實作為 sensitivity analysis 選項：preprocess_ecg.py 會把每個 window 的來源 record_id
  存進 NPZ（PTB-XL 優先用 metadata 的 patient_id，一位病人可能對到多筆紀錄；MIT-BIH/Chapman/CPSC/QTDB 用檔名本身，因為這些
  資料集的標準發布是一筆紀錄對一位病人，MIT-BIH 已知的 201/202 同病人例外有另外處理），inference.py 會把 record_id 寫進
  metrics_per_window.csv，`result_analysis.py paired-stats --group-by record` 會先對每個 record_id 內的所有 window 取平均，
  再用這些聚合值做 paired t-test/Wilcoxon（預設仍是 `--group-by window`，逐 window 比較）。**注意：這是新加的欄位，先前產生的
  NPZ／metrics_per_window.csv 沒有 record_id，要先重新跑 preprocess_ecg.py + inference.py 才能用 `--group-by record`。**
- 若分布不符合常態，可使用 Wilcoxon signed-rank test。
- 多重比較使用 Bonferroni 或 Holm correction。
- 顯著水準 alpha = 0.05。

建議報告方式：
- 主要表格分 dataset 呈現。
- Robustness 實驗用折線圖呈現不同強度與不同頻率下的變化。
- External test 使用同一套 metrics，清楚比較 PTB-XL、MIT-BIH、Chapman、CPSC 的落差。


十、視覺化結果

每個主要實驗至少放三類案例：
- 成功案例。
- 普通案例。
- 失敗案例。

每個案例建議顯示：
- Input ECG with Baseline Wander。
- Restored ECG。
- Clean reference。
- Residual error。
- PSD 或 spectrogram。

視覺化目的：
- 確認 Baseline Wander 是否真的被移除。
- 確認 QRS、ST、T wave 是否被保留。
- 呈現模型失敗模式，避免只展示成功案例造成偏誤。


十一、目前投影片架構的優點

目前投影片已有清楚主軸：
- 研究目標明確：Single-lead ECG Baseline Wander Removal。
- 使用 Lead II 建立一致 single-lead 設定。
- 以 PTB-XL 作為主要訓練資料。
- 使用 MIT-BIH、Chapman、CPSC 分別對應 cross dataset、cross hospital、cross device / population。
- 實驗涵蓋 in-domain performance、robustness、generalization、ablation、complexity。
- 評估方式包含客觀指標與視覺檢查。

整體方向合理，可以作為正式研究設計基礎。


十二、需要特別補強的部分

1. Clean reference 定義
- 需統一說法，避免 ground truth 定義被質疑。

2. Patient-wise split
- 必須明確寫出，這是避免 data leakage 的關鍵。

3. Baseline Wander 合成細節
- NSTDB 如何取樣、裁切、重取樣、scaling、對齊 window 都要可重現。
- NSTDB noise windows 需以固定 seed 切成 train / validation / test noise pools，避免訓練污染片段直接出現在 validation/test noisy-clean pairs。
- 目前 processed NPZ 內的 noisy ECG 為前處理階段固定合成，訓練時不是 on-the-fly augmentation；需在方法中說明，並將 training-time random baseline augmentation 視為後續可降低污染型態 overfitting 的改進方向。

4. Controlled robustness test
- 不應只使用單一 NSTDB baseline。
- 應加入不同強度、不同頻率與不同型態的 controlled baseline。

5. Metrics 主次
- 主指標不要太多。
- 建議主打 PRD、SNR improvement、low-frequency power reduction、R-peak/RR interval error。
- Cosine similarity 可以放，但應定位為輔助波形相似度指標。
- Reference-based metrics 僅能用在有 clean reference 的 synthetic evaluation。
- Low-frequency power reduction 需避免和前處理 high-pass filter 的頻段設定互相衝突。

6. Real-world no-reference test
- 建議加入，因為 synthetic baseline 不能完全代表真實環境。
- 此實驗不應回報 PRD、RMSE、SNR、cosine similarity 等需要 clean reference 的指標，應改用 no-reference 分析與視覺檢查。

7. External test 解讀
- MIT-BIH、Chapman、CPSC 可用於外部泛化測試。
- 若沒有 hospital、device、population metadata 的 subgroup analysis，應避免過度宣稱模型已完成嚴格的跨醫院、跨設備或跨族群因果驗證。


十三、推薦最終版本

最推薦的實驗環境如下：

1. 使用 PTB-XL Lead II 作為主要訓練資料。
2. 採用 patient-wise train / validation / test split。
3. 對所有資料集使用一致前處理流程。
4. 將 clean reference 定義為「經一致前處理後、尚未加入 Baseline Wander 的 ECG」。
5. 不將 0.5-40 Hz band-pass 視為唯一標準設定；建議優先採用 low-pass 40 Hz 或 0.05/0.1-40 Hz 等較保守前處理，並將 0.5-40 Hz 作為候選設定或 sensitivity analysis。
6. 使用 NSTDB Baseline Wander 作為主要訓練污染。
7. 使用 controlled synthetic baseline 測試不同強度與頻率的魯棒性。
8. 使用 MIT-BIH、Chapman、CPSC 做 external generalization test；若 metadata 足夠，再進一步做 hospital/device/population subgroup analysis。
9. 主要指標使用 PRD、SNR improvement、low-frequency power reduction、R-peak/RR interval error。
10. 輔助指標使用 RMSE、centered cosine similarity、QRS amplitude error、視覺比較與頻譜分析。
11. Reference-based metrics 只用於有 clean reference 的 synthetic evaluation；real-world no-reference test 使用 PSD/spectrogram、低頻能量變化、R-peak detection 穩定度與視覺檢查。
12. Baseline training recipe 採 paper-faithful optimizer / LR / scheduler 原則，但主要比較統一使用 convergence-controlled stopping：max epoch 50000、patience 20、min_delta 1.0e-4、validation PRD 選模。
13. 所有模型使用同一 validation fold 做 tuning 與 checkpoint selection，並完整報告 recipe manifest、實際停止 epoch、best PRD checkpoint 出現位置與任何 implementation deviation。
14. 加入 ablation study 與 complexity analysis。
15. 若時間允許，加入 real-world no-reference test。

一句話總結：
本研究的實驗環境應設計成「同一任務、同一 Lead II、同一前處理、同一資料切分、可重現 Baseline Wander 合成、各模型採 paper-faithful training recipe、同一套 evaluation metrics、可控制魯棒性測試、跨資料集外部驗證」的 benchmark。這樣比較的是各方法在最佳可辯護狀態下解同一個 Baseline Wander Removal 任務的效能，而不是誰比較適合同一組任意訓練超參數。


十四、目前專案實作對應

目前程式已將本文件的核心實驗流程落到以下工具：

1. 前處理與資料產生
- 程式：code/preprocess_ecg.py。
- 功能：讀取 ECG records，選 Lead II，filter，resample，window slicing，normalization，baseline wander synthesis，輸出 NPZ。
- 支援輸入：NPZ、NPY、CSV/TXT numeric arrays、WFDB records（需安裝 wfdb）。
- PTB-XL：依 metadata 中的 strat_fold / fold / ptbxl_fold 產生 train.npz、val.npz、test.npz。
- External datasets：MIT-BIH、Chapman、CPSC 產生 test-only NPZ。

2. 資料切分
- YAML 已明確設定 PTB-XL official folds。
- Training：folds 1-8，約 80%。
- Validation：fold 9，約 10%。
- In-domain test：fold 10，約 10%。
- External test：mit_bih.npz、chapman.npz、cpsc.npz、qtdb.npz，100% test only。
- Dataset loader 會要求 PTB-XL train/val/test NPZ 具備 fold metadata，並檢查 train/val/test 是否符合 official folds。

3. Baseline Wander 合成
- 程式：code/preprocess_ecg.py。
- 支援 NSTDB、sinusoidal、multi_sine、random low-frequency drift。
- 主訓練/評估用 noise_sampling: deepfilter + alpha_sampling: integer_percent_uniform，
  alpha_values: [0.2, 2.0]（對齊 DeepFilter 官方 Data_Preparation 的 randint(20,200)/100
  整數百分比抽樣）；alpha_values 只給單一值時視為固定強度（供 Experiment 2 sweep 用）。
- NSTDB noise windows 在 preprocess 階段以固定 seed 切成 noise_split ratio [0.8, 0.1, 0.1]：
  PTB-XL train 使用 train noise pool，PTB-XL validation 使用 validation noise pool，
  PTB-XL fold-10 test 與 MIT-BIH/Chapman/CPSC/QTDB external tests 使用 test noise pool。
  因為 noisy-clean pairs 會寫入 NPZ，所有模型讀到的是完全相同且固定的污染資料。
- Experiment 2 robustness sweep 另外用 robustness_alpha_values: [0.2, 0.6, 1.0, 1.5, 2.0]
  （對齊 DeepFilter／MECG-E 論文回報的 noise-amplitude 分段）。
- 支援 controlled_frequencies_hz，例如 0.05、0.1、0.2、0.3、0.5、0.8、1.0 Hz。

4. 訓練與測試
- 程式：code/train_supervised.py。
- 模型：mecg_e、mambattention_ecg、mambattention_stfrft_ecg、fcn_dae、deepfilter、drnn、descod_ecg_1shot/5shot/10shot 等。
- mambattention_stfrft_ecg 使用與 mambattention_ecg 相同的資料與主要 backbone 參數；核心差異是將 STFT 前處理替換為 learnable STFrFT。
- 支援 checkpoint、resume、early stopping、loss curves。
- 訓練結束會評估 PTB-XL fold 10，若 external NPZ 存在也會評估 MIT-BIH、Chapman、CPSC。
- 目前狀態（2026-08）：fcn_dae、drnn、deepfilter、descod_ecg_1shot/5shot/10shot、mecg_e、
  eddm、fir、iir 的架構/loss/optimizer/lr/betas/weight_decay/scheduler 已逐一對照各自論文
  或官方原始碼修正（見上「Baseline recipe 對齊現況」與 EXPECTED_TRAINING_BY_MODEL）。
  train_supervised.py 支援 Adam/AdamW/RAdam、none/StepLR/ExponentialLR/ReduceLROnPlateau、
  per-config grad_clip_norm、val_pcc / val_loss / val_prd 三種選模，且同時保存
  best_pcc_model.pt、best_prd_model.pt 與 best_model.pt。
  目前主要比較採統一 convergence-controlled stopping：train_epochs 50000、
  early_stopping_patience_epochs 20、early_stopping_min_delta 1.0e-4、selection_metric
  val_prd；optimizer、learning rate、scheduler、batch size 和 loss 仍依各模型論文或官方碼。

5. Inference
- 程式：code/inference.py。
- 輸出 restored_ecg.npz、metrics_summary.csv、metrics_per_window.csv、metrics_summary.json。
- 若 input 沒有 clean_reference，只輸出 no-reference 可計算指標。
- EDDM 若設定 num_shots > 1，restored_ecg.npz 會同時保存 restored_ecg（shot 平均）
  與 restored_ecg_shots（每個 stochastic reverse-process shot 的個別輸出）。

6. Experiment 2：Baseline Strength Robustness
- 程式：code/experiment_suite.py exp2-strength。
- 自動產生不同 alpha 的 PTB-XL fold 10 test NPZ。
- 自動跑 inference。
- 輸出 exp2_strength/summary.csv。

7. Experiment 3：Baseline Frequency Robustness
- 程式：code/experiment_suite.py exp3-frequency。
- 自動產生不同 frequency 的 PTB-XL fold 10 test NPZ。
- 自動跑 inference。
- 輸出 exp3_frequency/summary.csv。

8. Experiment 7：Ablation Study
- 程式：code/experiment_suite.py exp7-ablation。
- 自動產生 ablation configs。
- 目前包含 full、no_frequency_block、no_consistency_loss、no_complex_loss、no_time_loss、complex_input、waveform_input、with_attention_block。
- 可選擇直接批次訓練。
- 輸出 exp7_ablation/ablation_plan.csv 與 exp7_ablation/summary.csv。

9. Experiment 8：Complexity Analysis
- 程式：code/utils.py 的 profile_model_complexity，由 train_supervised.py 呼叫。

- 訓練結果也會輸出 spectrum_sample_*.png，包含 PSD / spectrogram 診斷圖。

11. 結果彙整與統計分析
- 程式：code/result_analysis.py。

- paired-stats：對兩個模型的 metrics_per_window.csv 做 paired t-test、Wilcoxon signed-rank test，並支援 Holm / Bonferroni correction。
